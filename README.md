# PESA-II 

A reproducible Python project with PESA-II-style region-based selection, ZDT1/2/3/4/6, DTLZ1-7, and standard Fonseca, Kursawe, Schaffer, and Viennet problems, per-run CSV/JSON output, metrics, separate front images, and Word/PDF comparison reports.

## Primary references
- Corne, Jerram, Knowles & Oates (2001), *PESA-II: Region-based Selection in Evolutionary Multiobjective Optimization*, GECCO 2001, pp. 283–290: https://research.manchester.ac.uk/en/publications/pesa-ii-region-based-selection-in-evolutionary-multiobjective-opt/
- Deb, Thiele, Laumanns & Zitzler (2002), *Scalable Multi-Objective Optimization Test Problems*, CEC 2002: https://doi.org/10.1109/CEC.2002.1007032
- Benchmark documentation: https://pymoo.org/problems/test_problems.html

## Install (Windows PowerShell)
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m experiments.run --benchmark ZDT1 --runs 10
python -m experiments.run --benchmark ALL --runs 10
# Additional unambiguous legacy benchmarks: FONSECA, KURSAWE, SCHAFFER, VIENNET
```

## Outputs
- `results/data/<benchmark>/run_###_seed_####.csv`: decision and objective vectors
- `metrics.csv`, `summary.json`: per-run metrics and mean/std
- `results/plots/<benchmark>/true_front.png`
- `results/plots/<benchmark>/obtained_front_seed_####.png`
- `results/plots/<benchmark>/comparison_seed_####.png`
- `results/reports/benchmark_comparison.docx` and `.pdf`

## Fidelity and scope warning
This is a **PESA-II-style baseline scaffold**, not yet a certified paper-faithful reproduction. See `AUDIT_FINDINGS.md` for benchmark conventions and remaining audit items. Region-based parent selection, an external non-dominated archive, and density-aware archive truncation are implemented; operator choices and archive/internal-population semantics must be checked line-by-line against the original paper before claiming exact replication.

The code additionally implements standard Fonseca-Fleming, Kursawe, Schaffer, and Viennet definitions. Fonseca, Kursawe, and Viennet reference sets are deterministic approximations generated by decision-space sampling and nondominated filtering; they are not exact analytical fronts. Schaffer has an analytical reference front. The attached PDF also includes Binh (1)/(3), Deb/Deb (2), Fonseca (2), Laumanns, Murata, Quagliarella, Rendon/Rendon (2), Schaffer (2), Srinivas, Tanaka, and Viennet (2). Ambiguous numbered variants are explicitly listed as unresolved in `benchmark_catalog.csv` instead of being guessed. Srinivas and Tanaka are constrained problems, and the current PESA-II runner does not enforce constraints, so they are marked as not yet runnable for valid constrained experiments.

True fronts are analytical for ZDT1-4 where applicable; ZDT6 is sampled directly from its analytical objective-space front. DTLZ1-4 have known analytical Pareto-front geometry; DTLZ5/6 use a lower-dimensional reference manifold and DTLZ7's front is disconnected. For higher objective counts, figures display the first three objectives and explicitly label the projection.

HV is implemented only for two objectives. IGD/GD are computed against the stored reference set and are not silently normalized. Compare metric values only under consistent reference sets, normalization, and HV reference points. The current scaffold's constrained benchmark handling is not enabled; do not report constrained legacy problems until constraint-domination is implemented and validated.
